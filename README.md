# Otterlove 🦦❤️

Затишний куточок для двох: спільна видра-улюбленець, місця й побачення, покупки та справи,
вішліст, записки, календар, бюджет пари. Українська, English, русский.

## Встановлення

1. Завантаж APK: [apk/Otterlove-0.4.0.apk](https://raw.githubusercontent.com/Deos-Machine/otterlove-updates/main/apk/Otterlove-0.4.0.apk)
   (актуальне посилання завжди в [`latest.json`](latest.json)).
2. Дозволь встановлення з браузера, якщо Android попросить.
3. Відкрий Otterlove, введи імена — і запроси партнера кодом пари в налаштуваннях.

## Оновлення

Застосунок сам перевіряє цей репозиторій під час запуску й пропонує оновитися.
Нова версія встановлюється поверх старої, дані зберігаються.

Перевірити APK можна за SHA-256 у [`latest.json`](latest.json).
